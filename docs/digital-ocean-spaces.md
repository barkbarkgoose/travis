## Frequently Asked Questions

What is DigitalOcean Spaces?

DigitalOcean Spaces is an object storage service that provides a simple and scalable way to store and serve large amounts of unstructured data. It's a [highly available](https://docs.digitalocean.com/products/spaces/details/availability/), S3-compatible service designed for storing things like images, videos, backups, and static website assets. Spaces includes a built-in CDN to speed up content delivery.

How does Spaces support developers at enterprise businesses in data management?

Spaces can be used for a wide range of use cases, from hosting static websites and delivering video streams to archiving backups and storing large datasets for AI/ML training. Its S3 compatibility ensures easy data migration and seamless integration with a vast ecosystem of tools. DigitalOcean also provides robust and [up-to-date documentation](https://docs.digitalocean.com/products/spaces/) for using and scaling with Spaces.

Does Spaces have a CDN?

Yes, every Space includes a [built-in CDN](https://docs.digitalocean.com/products/spaces/how-to/enable-cdn/) at no extra cost. This helps improve the performance of your applications by caching and delivering content from a location closer to your users, reducing latency. This helps your organization maintain user satisfaction even as your operations grow.

How is Spaces different from Block Storage?

Spaces is an object storage service ideal for unstructured data and static assets, and it's accessed via an API over the internet. Block Storage provides a traditional block-level storage volume that can be attached to a [Droplet](https://www.digitalocean.com/products/droplets), functioning like a local hard drive. Use Spaces for scalable, global access to files and Block Storage for high-performance, persistent storage for your databases or Droplets.

What are some common use cases for DigitalOcean Spaces?

Common use cases for Spaces include hosting static websites, storing and serving user-uploaded content, and creating backups of your applications and databases. It's also frequently used as a data lake for analytics and a repository for large files needed by other services.
